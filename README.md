# 📱 Social Media Platform

> A full-stack MERN social media application for connecting users, sharing posts and interacting through likes, comments, follows, notifications and messaging.

## 🚀 Features

* 🔐 User registration and login
* 👤 User profiles
* 📝 Create posts
* 🖼️ Media-based posts
* ❤️ Like and unlike posts
* 💬 Comments
* 👥 Follow and unfollow users
* 🔔 Notifications
* 💬 User messaging
* 🔒 Protected routes
* 📱 Responsive UI

## 🛠️ Tech Stack

* React.js
* JavaScript
* Tailwind CSS

* MongoDB

* Axios

## ⚙️ Installation

```bash
git clone YOUR_REPOSITORY_URL
cd social-media-platform
npm install
npm run dev
```

Create the required `.env` files for frontend and backend configuration.
